# ⏱ BiTimer — Minimal Chrome Timer Extension

**BiTimer** is a lightweight, minimalist, and adaptive timer designed for  
**test sessions, exercises, focus sprints, and UX/UI testing**.

The goal is simple:  
👉 **start fast, stay focused, no distractions.**

---

## ✨ Features

- ⏱ Countdown timer (minutes / seconds)
- ▶ Start / Pause
- ➕ Add +1 minute
- 🔊 Volume slider for end sound
- 🎨 Clean & modern UI inspired by productivity tools
- ⚡ Works offline
- 🧩 Built with **vanilla HTML, CSS, and JavaScript**
- 🆓 Free & open-source

---

## 🎨 Design Philosophy

- Ultra-minimal UI
- Large, readable digital timer
- Soft shadows & rounded surfaces
- Single accent color (purple) for focus
- Optimized for **Chrome extension popup**
